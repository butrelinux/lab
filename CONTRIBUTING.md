# Contributing to butrelinux

do whatever.  if I like it I'll accept your PR.  no bureaucratic bullshit here.  

I'll probably like it better if you follow existing conventions:  
    - kebab case for filenames  
    - try not to shit up the root too much  
    - make sure there's one trailing newline without a tab or space or whatever in it  
    - use ```#!/usr/bin/env bash``` where it makes sense.  
    - test your contribs first.  that's what butrelinux/lab is for  

nothing crazy.  
also, just don't be a dick.
